# QA Academy — обучение Junior QA с Java

Персональный русскоязычный тренажёр. **Разработка не завершена.** Основная опубликованная ветка — `main`.

## Учебный экран
В `prototype/lesson.html` — объяснение SQL, шесть небольших заданий, проверка вариантов ответа, объяснения, подсказки, повтор ошибок и локальный прогресс в браузере. Это прототип учебного взаимодействия, не серверная платформа с аккаунтами.

В `bank.py` сохранены основные учебные материалы: вопросы с вариантами, самостоятельные SQL-задания и открытые вопросы с эталонами. Они пока не подключены целиком к экрану. Расширение до 1070 содержательных заданий остаётся незавершённым; установка skills не меняет этот счётчик.

## Skills — уже в проекте
В `.agents/skills/` находятся пять самостоятельных проектных адаптаций проверенных skills с skills.sh и координатор `qa-academy-development`:

- `frontend-design` — дизайн и читаемость уроков;
- `web-design-guidelines` — доступность и удобство интерфейса;
- `webapp-testing` — реальные браузерные проверки;
- `systematic-debugging` — воспроизведение и причины ошибок;
- `verification-before-completion` — проверка результатов перед отчётом;
- `qa-academy-development` — правила процесса для всего проекта.

Это **адаптированные инструкции**, не полные оригинальные upstream-пакеты. Лицензии лежат рядом с файлами. Вспомогательные инструменты, Python/Java/Playwright и браузеры сами по себе не устанавливаются. Источники, область установки и команды для необязательной установки оригиналов: [docs/SKILLS.md](docs/SKILLS.md).

После получения актуальной версии репозитория Codex может обнаружить `.agents/skills`. Вызов: `$qa-academy-development` или конкретный skill. Обнаружение на личном компьютере пользователя не проверено.

## Проверки
Проверка структуры навыков: `python tools/check_skills.py`.

`tests/test_lesson_browser.py` относится к прежнему прототипу. Его ранее записанный результат 11 DOM-тестов passed / 3 skipped не является проверкой новой платформы или текущей установки. Исторический отчёт: [docs/VERIFICATION.md](docs/VERIFICATION.md). Текущий статус установки: [docs/INSTALLATION-STATUS.md](docs/INSTALLATION-STATUS.md).

## Запуск прототипа
Открыть `prototype/lesson.html` в браузере либо запустить из корня:

```sh
python -m http.server 8765 --bind 127.0.0.1 --directory prototype
```

Затем открыть `http://127.0.0.1:8765/lesson.html`.

Учебный язык программирования — **Java, не JavaScript**. Все записи в GitHub — только через `VYCHESLAV1988`, только в этом репозитории, без force push. Не коммитить личные базы, пароли, токены и ответы пользователя.
