# QA Academy — обучение Junior QA с Java

Персональный русскоязычный тренажёр. **Разработка не завершена.** Основная опубликованная ветка — `main`.

## Учебный экран — редакция вопросов 2
В `prototype/lesson.html` — объяснение SQL, шесть заданий, проверка вариантов, подсказки, повтор ошибок и локальный прогресс. Вопросы вынесены в `prototype/sql-foundations.js`: этот технический файл нужен браузеру и не является курсом JavaScript.

После замечания о качестве формулировок у каждого задания теперь есть свои явно показанные данные, расшифровка полей, полный запрос или обозначенный заполняемый фрагмент. После ответа показаны выбранный и правильный варианты, объяснение конкретной ошибки, три шага решения и ожидаемый результат SQL. Старые попытки не удаляются, но отделены от новой редакции; сохранение миграции ещё не проверено в обычном браузерном окружении.

В `bank.py` сохранены остальные учебные материалы. Они не подключены целиком к экрану и не прошли текущую проверку. Расширение до 1070 содержательных заданий остаётся незавершённым. Этот этап исправляет качество шести вопросов, а не увеличивает счётчик.

## Skills — уже в проекте
В `.agents/skills/` находятся проектные адаптации `frontend-design`, `web-design-guidelines`, `webapp-testing`, `systematic-debugging`, `verification-before-completion` и координатор `qa-academy-development`.

Это адаптированные инструкции, не полные оригинальные upstream-пакеты. Лицензии лежат рядом. Установка инструкций не устанавливает Python, Java, Playwright или браузеры. Источники и область установки: [docs/SKILLS.md](docs/SKILLS.md).

Для этого исправления прочитаны и применены systematic-debugging, webapp-testing и verification-before-completion. Обнаружение skills в личном Codex пользователя не проверено. Проверка структуры: `python tools/check_skills.py`.

## Проверки текущего изменения
`python -m unittest discover -s tests -p test_sql_content.py -v` — 6 успешных тестов контента, включая исполнение всех эталонов на показанных данных и границы AND.

Обычный HTTP-запуск браузерной проверки заблокирован средой с ERR_BLOCKED_BY_ADMINISTRATOR до открытия страницы. Ограниченный прогон:

```sh
QA_INLINE_HTML=1 QA_CHROMIUM_PATH=/usr/bin/chromium python -m unittest discover -s tests -v
```

23 теста: **19 passed, 4 skipped**. Это 13 DOM/browser-проверок и 6 проверок SQL-контента. Четыре проверки сохранения/перезагрузки требуют обычного origin и не засчитываются как успешные. Вне ограниченной среды запускать без QA_INLINE_HTML. Подробный отчёт и ограничения: [docs/SQL-REVIEW.md](docs/SQL-REVIEW.md). Прежний отчёт: [docs/VERIFICATION.md](docs/VERIFICATION.md).

## Запуск
Скачать актуальный репозиторий целиком. Открыть `prototype/lesson.html` в браузере. **Рядом должен оставаться `sql-foundations.js`**. В заголовке должно быть «Редакция вопросов 2». Старый скачанный файл автоматически не обновляется.

Либо из корня:

```sh
python -m http.server 8765 --bind 127.0.0.1 --directory prototype
```

Затем открыть `http://127.0.0.1:8765/lesson.html`.

Прототип не имеет серверных аккаунтов, не исполняет произвольный SQL/Java и не является защищённым экзаменом. При смене пути локального файла браузер может использовать другое место хранения прогресса.
