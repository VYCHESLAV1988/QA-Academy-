# QA Academy — обучение Junior QA с Java

Рабочая ветка: `build/java-learning-v0.2`. Это незавершённый проект, не готовый полный курс.

## В этом изменении
Подключён собственный проектный skill `.agents/skills/qa-academy-development/SKILL.md`; найдены и применены пять внешних skills с skills.sh. Источники, назначение и точные ограничения установки: [docs/SKILLS.md](docs/SKILLS.md).

Реализован проверяемый экран урока [prototype/lesson.html](prototype/lesson.html): объяснение, шесть заданий по одному, оценка 0/5 или 5/5, разбор ошибки, подсказки, отдельный учёт самостоятельных ответов, повтор ошибок, светлая/тёмная тема и попытка локального сохранения.

Шесть заданий — только примеры взаимодействия в прототипе, не уменьшение существующей учебной программы. bank.py сохранён. Переход к модульной платформе описан в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Посмотреть экран
Скачать репозиторий и открыть `prototype/lesson.html` в браузере. Если политика браузера запрещает storage или открытие файла, использовать разрешённое локальное окружение. Для обычной разработки: `python -m http.server 8765 --bind 127.0.0.1 --directory prototype`, затем открыть `http://127.0.0.1:8765/lesson.html`.

Это не экран регистрации и не серверная база пользователей. В прототипе нет произвольного исполнения SQL/Java и защищённого экзамена. Не размещать его как готовый публичный SaaS.

## Проверки
`tests/test_lesson_browser.py` содержит 14 браузерных тестов. В рабочей среде 11 DOM-тестов прошли, 3 проверки persistence пропущены; подробности и команды: [docs/VERIFICATION.md](docs/VERIFICATION.md).

## Разработка через Codex
Прочитать AGENTS.md, вызвать `$qa-academy-development`. Установка оригинальных сторонних skills на компьютере пользователя пока не выполнена; команды находятся в docs/SKILLS.md. Сначала прочитать выбранный skill, затем выполнить и проверить один ограниченный этап.

Учебное направление — **Java, не JavaScript**. Все записи в GitHub разрешены только через `VYCHESLAV1988` и только в этом репозитории. Не отправлять личную базу, пароли и токены.
