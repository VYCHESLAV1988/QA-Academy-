# SQL Foundations: английские вопросы и русский разбор

Дата: 2026-10-15. База изменения: main 3203f6306df96380fbf27045960cd1b2db10a164.

## Изменено
Шесть основных SQL-вопросов получили английскую постановку и варианты, переключаемый перевод, английский Sample answer и словарь Key terms. Пояснения для каждого выбранного варианта и шесть отдельных примеров закрепления написаны вручную. Смысл, идентификаторы и правильные индексы основных вопросов редакции 2 сохранены; sql-foundations.js побайтово не меняется. Подсказки и повторная отправка не увеличивают самостоятельный результат. Переключение перевода не сбрасывает выбранный ответ.

С экрана убраны служебный footer и подписи о прототипе/редакциях. HTML, CSS, поведение, техническое содержимое и языковой слой отделены. Существующие skills и основной каталог bank.py не удалены и не изменены этим этапом. Это изменение качества и языка текущего урока, НЕ создание 1070 заданий.

В локальной рабочей копии проверены:
- tests/test_lesson_browser.py;
- tests/test_tutor_feedback.py;

Команда: `QA_INLINE_HTML=1 QA_CHROMIUM_PATH=/usr/bin/chromium python -m unittest discover -s tests -v`.
34 tests: **29 passed, 0 failed, 5 skipped**. Это целевой прогон этих трёх файлов, не CI всего репозитория. Пропуски: reload persistence, сохранение темы, повреждённый storage при reload, история редакции 2 после reload, сохранение языкового режима. Они требуют доступного origin.

Обычная HTTP-навигация протестирована один раз: ERR_BLOCKED_BY_ADMINISTRATOR до загрузки приложения. Политики не менялись. DOM-прогон использует действительные HTML/CSS/JS через set_content, без подмены storage. Он НЕ проверяет сетевую загрузку ресурсов или долговременное сохранение.

Проверены все 18 основных вариантов и все шесть закреплений, защита от двойной отправки, пустой ответ, подсказки, повтор ошибок, клавиатура, English question и Sample answer после отправки, переключение перевода без сброса результата, отсутствие служебного footer, мобильная ширина 320/390/768, SQL-эталоны на показанных данных и границы AND.

Визуально просмотрены снимки вопроса AND и подробного разбора. Исправлено переполнение длинного текста на узком экране, обнаруженное в прерванной рабочей версии. Первоначальный неверный текст ожидания в тесте исправлен под отредактированную формулировку; после этого выполнен повторный прогон.

## Запуск
Получить main целиком, сохранить рядом файлы prototype/lesson.html, lesson.css, lesson.js, sql-foundations.js, tutor-feedback.js, interview-language.js. Открыть lesson.html. Старые копии на компьютере автоматически не обновляются. Формат текущего экрана узнаётся по SQL Foundations, English question и переключателю «Показывать перевод». Для обычной разработки использовать разрешённый локальный HTTP-сервер.
