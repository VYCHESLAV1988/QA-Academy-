# Учебная платформа, а не один файл вопросов

## Текущее изменение
Добавлены проектный skill, реестр источников, отдельный работающий прототип урока и браузерные проверки. Существующий bank.py не удалён и не переименован: сначала нужна миграция, сохраняющая задания и идентификаторы. Прототип содержит шесть примеров для проверки учебного взаимодействия, а не заменяет существующие материалы.

## Целевые границы модулей — ещё не реализованы
- curriculum/: версионированные темы, уроки, задания, эталоны, источники и рубрики. Не исполняемый Python с огромными строковыми блоками.
- learning/: выбор следующего задания, повторение и условия перехода. Зависит от учебной программы, не от HTML.
- assessment/: отдельные проверщики вариантов, SQL и самооценки открытого ответа. Формат результата: score, max_score, assisted, evidence, explanation.
- persistence/: пользователи, сессии, попытки, прогресс, миграции. Пароли и токены не хранятся открытым текстом.
- web/: страницы и API. Ответы не отправляются клиенту заранее в экзаменационном режиме.
- tests/: unit, API, безопасность и браузерная регрессия. Учебный SQL не имеет доступа к базе пользователей.

Это модульный монолит для личного приложения. Микросервисы и смена стека сами по себе не делают проект профессиональным. Java остаётся языком учебной автоматизации; выбор технологии интерфейса — отдельный вопрос.

## Следующая проверяемая реализация
1. Перенести контент bank.py в структуру curriculum с тестом неизменности ID, числа вопросов и эталонов. До успешного сравнения оставить адаптер совместимости.
2. Подключить экран урока к серверному API вместо встроенных демонстрационных данных.
3. Реализовать базу пользователей и журнал попыток, серверное начисление баллов и защищённые сессии.
4. Проверить реальное сохранение после перезапуска и изоляцию двух аккаунтов.
5. Подключить SQL-песочницу, затем Java-теорию и автоматизацию. Не добавлять курс JavaScript.
6. Расширять материалы после проверки источников и качества, не обещать все вопросы всех интервью.

## Дизайн урока
Три последовательных шага: «Разобраться», «Потренироваться», «Мой результат». Один вопрос на экране, пример до проверки, доступная подсказка и разбор после ответа. Неверный ответ не блокирует обучение. Ошибки возвращаются отдельно. Основной текст крупный, цвета не являются единственным индикатором результата.

## Известные границы прототипа
Нет аккаунтов, серверной базы, настоящего SQL-исполнения и всего курса. Ответы находятся в клиентском коде: этот прототип не подходит для защищённого экзамена. localStorage — удобство личного просмотра, не защита от изменения баллов. Доступность оценена частично; аудит screen reader и нескольких движков ещё нужен.
