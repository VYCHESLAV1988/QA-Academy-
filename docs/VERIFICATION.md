# Проверка этапа skills + экран урока

Дата: 2026-10-15. Объект проверки: prototype/lesson.html и tests/test_lesson_browser.py, не всё приложение.

## Выполнено
Полный SKILL.md прочитан для frontend-design, web-design-guidelines, webapp-testing, systematic-debugging и verification-before-completion.

Команда в текущей среде:

```sh
QA_INLINE_HTML=1 QA_CHROMIUM_PATH=/usr/bin/chromium python -m unittest discover -s tests -v
```

14 объявленных тестов: **11 passed, 0 failed, 3 skipped**. HTML передавался в Chromium напрямую через Playwright set_content, без сетевой навигации и без подмены localStorage. Это DOM-проверки реального интерфейса, не полные end-to-end тесты сервера.

Пройдены: исходный экран; пустая отправка; неверный ответ и объяснение; верный ответ и защита от двойного submit; отдельный учёт подсказки; повторение только ошибок; завершение шести заданий; мобильная ширина 390 px без горизонтального overflow страницы; подтверждение очистки; управление клавиатурой; сообщение при запрете browser storage.

## Пропущено
Сохранение после перезагрузки, сохранение темы после перезагрузки, восстановление после повреждённого localStorage. Для них нужен нормальный origin и разрешённая навигация. Не засчитывать их как Passed.

Первый HTTP-прогон: 14 ошибок подготовки окружения с ERR_BLOCKED_BY_ADMINISTRATOR. Навигация file:// также заблокирована. Политики браузера не менялись. После этого выполнена ограниченная DOM-проверка; она не заменяет HTTP-проверки.

## Визуальная проверка
Просмотрен скриншот настольного экрана. Текст и таблица читаются, элементы не перекрываются. На скриншоте видно реальное предупреждение о недоступном storage — оно не скрыто ради демонстрации. Мобильная ширина дополнительно проверена assertion.

## Не выполнено
Полное приложение, backend/API, вход, изоляция пользователей, миграция bank.py, SQL-исполнение, запуск Java, Windows, Safari/Firefox, полноценный аудит screen reader и npm-установка сторонних skills.

## Повтор в обычной среде
Установить Playwright для Python и Chromium согласно официальной документации. Из корня выполнить `python -m unittest discover -s tests -v` без QA_INLINE_HTML. Нужны все 14 успешных тестов; missing browser/dependencies — ошибка окружения, не повод поставить успех.
